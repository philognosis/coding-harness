# Knowledge base

Sourced research notes written by `/ingest`, one topic per file. A note records
what we verified, on which date and version, so the next session does not
repeat the reading.

Each note has: `Checked: <date, versions>`, `Answer`, `Facts` (with links),
`How we would use it`, `Risks and limits`, `Open questions`.

A note older than 60 days is re-checked before anyone relies on it.
