Idea 05 · The builder is not the reviewer

Nobody grades

their own work.

The reviewer starts with a fresh context. It sees the code as written, not the intent behind it.

A session that wrote the code also carries the reasoning that led to it, so it tends to approve its own assumptions. The kit’s /gate command hands the diff and the spec to a reviewer subagent that never saw the build. Subagents have their own context window, which is what makes the review independent.
