Idea 01 · Stateless agent, stateful repo

If it matters next week,

it’s a file.

The agent holds nothing. The repo holds everything:
goals, decisions, lessons, plans.

Chat history disappears; files do not. So anything the agent must know in a later session is written into the repo, where the next session, and the next tool, can read it. This is why the kit creates docs/GOALS.md, docs/decisions, docs/LESSONS.md and plan files.
