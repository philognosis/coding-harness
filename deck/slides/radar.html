The learning loop. /radar reads release notes and changelogs for everything on your watchlist, keeps only what would change how you build, and sorts each item into one of four rings. It also audits the harness itself: both Claude Code and Cursor change often, so it flags anything the kit works around that is now built in. Nothing new reaches the codebase without passing through /ingest and /decide. And /wrap ends every session by teaching back the techniques that were new to you.
