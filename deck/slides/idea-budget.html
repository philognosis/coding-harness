Idea 02

Context is a budget.

The more you load, the less reliably any one line is followed.

Always

AGENTS.md

86 lines. The project, the commands, the boundaries. Read at the start of every session.

When relevant

Rules

Standards for Python, UI, tests and agents. Each loads only when a matching file is touched.

On demand

Skills

Whole workflows. Only a one-line description is loaded until you call one.

This is progressive disclosure. Claude Code’s own docs advise keeping the always-loaded file under 200 lines because longer files reduce adherence. So the kit keeps one short always-on file and pushes detail into rules that load by file path and skills that load on demand.
