The workflow, with one new step. /model sits between research and planning: the agent reads the code map, writes the types, the transition table, its tests and the import boundary, and shows you the generated state diagram. A wrong arrow there costs a minute; after the build it costs a rewrite. /build now deletes what it replaces and changes state only through the transition function, and /gate requires evidence per acceptance criterion: a test, an eval score or a screenshot of the running app. Skip /model when a change has no lifecycle and adds no module.
