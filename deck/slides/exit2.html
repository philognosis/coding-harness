Hooks, up close

The exit code that means no.

A hook runs before the agent acts. Exit with 2 and the action is blocked. The message tells the agent why, so it changes course.

Exit 1 does not block. Every guard in the kit uses 2.

The single most useful detail about hooks. In Claude Code, a PreToolUse hook that exits with code 2 stops the tool call, and whatever it wrote to stderr is shown to the agent as the reason. Cursor’s docs describe the same rule. The kit’s guard_bash.py uses it to block pushes to main, force-pushes, pip install and npm install, among others.
