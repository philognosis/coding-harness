Version 1 had eight layers that guard what the agent does. Version 2 puts a design layer above them that guards what the code can say: types, state machines and import boundaries, so an illegal state or a wrong-way dependency fails the type check. Two guards also grew: the file guard now blocks hand edits to the generated code map and asks before the golden eval set is changed, and CI now fails on a stale code map or a project lint rule.
