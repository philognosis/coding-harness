The talk · All Code Is Slop (Except Mine), Lauren Tan

Move every decision up.

01

Codebase design

APIs that make the mistake impossible.

02

Static analysis

Lint, types and compilers catch what remains.

03

Verification

Run it. Prove the behaviour.

04

Prose

Rules and skills, for judgment only.

05

Human review

The costliest layer should carry the least.

The talk’s core idea, in my words: rank the places a decision can live and push each recurring correction as high as it will go. Her team bans patterns in code, puts guidance in lint messages, deletes stale examples agents would copy, and has agents prove behaviour by running the app. Reported figures (about 3,000 of her pull requests and 11,000 from the team in a month, roughly 0.5% reverted) are her own and unaudited; the revert rate counts reverts only.
