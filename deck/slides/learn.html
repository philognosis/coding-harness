Only now, write a sentence.

How the harness improves itself, revised. Version 1 let a correction start as a note and graduate upward. Version 2 starts at the top: redesign so the mistake cannot be written; if not, a static check; if not, something that runs; and only then a rule in prose. It also fixes or deletes existing instances of the mistake in the same change. Reasons and goals still go to decision records, because code cannot hold a why.
