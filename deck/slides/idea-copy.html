Idea 06 · The repo is the teacher

Agents copy what they find.

Leave it worth copying.

Delete what you replace. No workaround, dead code or warning comment left behind.

New in version 2. A leftover workaround reads to an agent as an established pattern, and each copy adds another example. So the build step now deletes what it replaces in the same commit, the reviewer looks for residue, and /learn cleans up existing instances of a mistake when it adds the rule against it. A rule with old violations left in place loses to the examples around it.
