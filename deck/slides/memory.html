Project memory. These four hold what code cannot: what you want, why you chose it, what went wrong, and what you learned from outside. What the code contains is no longer written down by hand; docs/CODEMAP.md is generated from the source. A session-start hook still prints goals, open plans, recent decisions and lessons.
