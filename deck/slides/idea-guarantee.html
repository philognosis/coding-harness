Idea 03

Advice versus guarantee.

Markdown

Usually followed.

AGENTS.md, rules, skills. The right home for standards and judgment.

Code

Always enforced.

Hooks, linters, CI. The only home for anything that must never happen.

If breaking it would hurt, don’t ask. Enforce.

An instruction file is a request the model usually honours. A hook or a CI check runs every time regardless of what the model remembers. The kit puts “never push to main” and “never read .env” in code, and style preferences in markdown.
