The new toolkit.

AGENTS.md

One brief, every agent

The always-loaded instruction file.

Rules

Scoped standards

Load only for the files they match.

Skills

Workflows on demand

A folder of steps, run as /name.

Subagents

Separate minds

Helpers with their own context window.

Hooks

Scripts that can say no

Fired on agent events. They can block.

Worktrees and headless runs

Many agents at once

Each in its own copy of the repo.

Six building blocks. AGENTS.md is a plain-markdown convention many coding agents read. Rules are standards scoped by file path. Skills are folders with a SKILL.md, invoked as slash commands. Subagents run in their own context. Hooks are scripts the tool runs on events such as “before a shell command”. Git worktrees and headless runs let several agents work in parallel or unattended. MCP servers, not shown, connect agents to outside tools and data.
